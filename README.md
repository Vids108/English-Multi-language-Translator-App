# VerbaFlow - English Multi-language Translator & Learning Assistant

An interactive desktop application built with Python and Tkinter that helps users translate text, generate speech, search word meanings, and manage learning notes in multiple languages.

---

## ✨ Features

- 🌍 Translate English text into 20+ languages using Google Translator.
- 🔊 Generate and play natural-sounding speech using Google Text-to-Speech (gTTS).
- 📖 Search word meanings, pronunciation, and examples using the Dictionary API.
- 📝 Save, translate, and manage learning notes through an intuitive interface.

---

## 🛠 Tech Stack

- Python
- Tkinter
- ttkbootstrap
- Google Translator (deep-translator)
- gTTS
- pygame
- pyttsx3
- pydub

- Dictionary API

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/VerbaFlow.git
```

### Navigate to the project

```bash
cd VerbaFlow
```

### Install dependencies

```bash
pip install ttkbootstrap gTTS pygame pyttsx3 deep-translator requests pydub
```

### Install FFmpeg (Recommended)

Download FFmpeg and add it to your system PATH for MP3-to-WAV conversion.

---

## ▶️ Run the Application

```bash
python main.py
```
